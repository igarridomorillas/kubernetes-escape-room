# Workshop Presentation (`Slidev`)

This directory contains the [Slidev](https://sli.dev) presentation deck for the **Kubernetes Escape Room** workshop, along with contributor instructions for running the slides locally and working with AI coding agents via the Slidev Skill and Model Context Protocol (MCP) server.

## 🚀 Quick Start (Local Development)

From the **repository root** (using `make` or `npm`):

```bash
# 1. Install dev & presentation dependencies (shellcheck, Slidev packages, Playwright Chromium & the pinned agent skills)
make setup-dev

# 2. Start the live-reloading Slidev dev server (http://localhost:3030)
make slides

# 3. Build and export deck to PDF (docs/presentation/slides-export.pdf)
make slides-export

# Nexthink meetup variant (Halloween theme, presenters, Nexthink and hiring slides)
make slides-nexthink
make slides-nexthink-export      # docs/presentation/slides-nexthink-export.pdf
```

### Two decks, one content

`slides.md` is the original workshop. `nexthink/slides.md` is the meetup variant: it adds the presenters, Nexthink and hiring slides and its own theme. Both pull the workshop slides and speaker notes from `shared/workshop.md` with `src:`, so edit shared slides there. Each entry directory carries its own `style.css`, `global-bottom.vue` and `public/`, because Slidev uses the entry's directory as its root.

Once `make slides` is running, open:
- **Presentation View:** `http://localhost:3030`
- **Presenter View (speaker notes & timer):** `http://localhost:3030/presenter`
- **Slide Overview Grid:** `http://localhost:3030/overview`

Or directly via `npm`:

```bash
npm --prefix docs/presentation install
npx --prefix docs/presentation playwright install chromium
npm --prefix docs/presentation run dev
npm --prefix docs/presentation run build
npm --prefix docs/presentation run export
```

Or if your shell is already inside `docs/presentation/`:

```bash
cd docs/presentation
npm install
npm run dev
```

## 🤖 AI Agent Setup: Slidev Skill + MCP Server

Contributors can author, inspect, reorder, and update slides using AI agents powered by two complementary integrations:

### 1. Slidev Agent Skill (`.agents/skills/slidev/`)

The [Slidev skill](https://github.com/slidevjs/slidev) gives AI agents reference documentation on Slidev Markdown syntax, headmatter, layouts, code highlighting, Mermaid diagrams, click animations, and the built-in MCP server.

The skill files are **not committed** (`.agents/skills/` is gitignored); only `skills-lock.json` is tracked. `make setup-dev` restores the pinned version automatically. To restore it on its own, run this at the repository root:

```bash
npx skills experimental_install
```

To add or refresh it (also updates the lockfile): `npx skills add slidevjs/slidev`. Add `-g` to install it globally for all your projects instead.

- **Location:** `.agents/skills/slidev/SKILL.md` (with detailed guides under `.agents/skills/slidev/references/`)
- **Lockfile:** `skills-lock.json`

### 2. Slidev MCP Server (`slidev mcp`)

Slidev ships a built-in MCP server that exposes structured slide-level operations (`slidev-list-slides`, `slidev-get-slide`, `slidev-update-slide`, `slidev-insert-slide`, `slidev-remove-slide`, `slidev-move-slide`, `slidev-goto-slide`). Prefer these MCP tools over raw Markdown text edits so multi-slide separators (`---`) and frontmatter blocks are parsed safely.

#### A. Running from the Repository Root (Pre-configured)

Because the Slidev `package.json` lives in `docs/presentation/` (keeping the repository root clean for the Bash harness), `npx` uses `--prefix docs/presentation` to resolve the local `@slidev/cli` binary (`slidev`) and targets `docs/presentation/slides.md`.

> **Prerequisite:** run `make setup-dev` (or `npm --prefix docs/presentation install`) first. Without `docs/presentation/node_modules`, the MCP server fails to start (`CONNECTION_CLOSED`).

This configuration is already checked into:
- `.agents/plugins/slidev/mcp_config.json` (auto-discovered by **Antigravity**)
- `.mcp.json` (used by **Claude Code**, **Cursor**, and standard MCP clients)

```json
{
  "mcpServers": {
    "slidev": {
      "command": "npx",
      "args": [
        "--prefix",
        "docs/presentation",
        "slidev",
        "mcp",
        "docs/presentation/slides.md"
      ]
    }
  }
}
```

#### B. Running Directly Inside `docs/presentation/`

If you launch your editor or agent with `docs/presentation/` as the working directory (or if `slides.md` and `package.json` are in your current working directory), the equivalent MCP configuration is:

```json
{
  "mcpServers": {
    "slidev": {
      "command": "npx",
      "args": ["slidev", "mcp", "slides.md"]
    }
  }
}
```

> **Why `--prefix docs/presentation` is required at the root:** On npm, the Slidev CLI package is `@slidev/cli` (which installs the `slidev` executable into `docs/presentation/node_modules/.bin/slidev`); there is no standalone `slidev` package on the npm registry. Running `npx slidev` from the repository root without `--prefix docs/presentation` fails with `E404 Not Found`. Passing `--prefix docs/presentation` resolves the local binary while keeping the working directory at the repository root.
>
> **Why `playwright-chromium` is required for PDF export:** `slidev export` launches headless Chromium via Playwright to render each slide. Both `"playwright-chromium"` in `docs/presentation/package.json` and the Chromium browser binary (`npx --prefix docs/presentation playwright install chromium`, run automatically by `make setup-dev` and `make slides-export`) must be present.

#### C. Connecting via Live Dev Server (Streamable HTTP)

When `npm --prefix docs/presentation run dev` is running on port `3030`, Slidev also exposes a Streamable HTTP MCP endpoint at `http://localhost:3030/__mcp` (which supports `slidev-goto-slide` for live slide navigation):

```json
{
  "mcpServers": {
    "slidev": {
      "url": "http://localhost:3030/__mcp"
    }
  }
}
```

## 🛠️ Available Slidev MCP Tools

| Tool | Description |
| :--- | :--- |
| `slidev-get-info` | Deck overview: entry path, title, slide count, markdown files, and server URL |
| `slidev-list-slides` | List all slides with 1-based slide number, title, layout, and source file |
| `slidev-get-slide` | Read the full source of a single slide (frontmatter, content, and presenter notes) |
| `slidev-update-slide` | Update content, presenter notes, and/or frontmatter of a specific slide |
| `slidev-insert-slide` | Insert a new slide after an existing slide number |
| `slidev-remove-slide` | Remove a slide by its 1-based number (except slide 1, which holds headmatter) |
| `slidev-move-slide` | Reorder slides by moving a slide before or after another slide |
| `slidev-goto-slide` | Navigate the live presentation to a slide (requires running dev server) |
